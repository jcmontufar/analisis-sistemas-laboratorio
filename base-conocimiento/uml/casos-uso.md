# UML de casos de uso

> Fuente académica pendiente. Contenido complementario y reglas del encargo.

## Definición y propósito

Modelo del valor observable que el sistema ofrece a actores externos, dentro de un límite definido.

## Elementos y reglas

Actores, casos, asociaciones, límite, generalización y dependencias `include`/`extend`. `include` apunta al comportamiento obligatorio reutilizado; `extend` apunta al caso base.

## Ejemplo disponible

`plantillas/uml/ejemplo-casos-uso.puml`.

## Errores frecuentes

Modelar pantallas, llamar “actor” a una parte interna o invertir dependencias.
