# Prototipos

> Regla DERCAS y vacíos: `dercas-y-prototipos.md`.

## Definición y propósito

Representación evaluable de una interacción o interfaz utilizada para aclarar y validar requerimientos.

## Elementos y reglas

Objetivo, actor, datos, acciones, validaciones, estados y correspondencia con requerimientos. Declarar el nivel de fidelidad.

## Ejemplo disponible

`plantillas/prototipo/plantilla.md`.

## Errores frecuentes

Tratar el prototipo como especificación completa o diseñar pantallas sin escenario ni validación.

Instrucciones DERCAS, “Prototipo”; PPTX, diap. 8.
