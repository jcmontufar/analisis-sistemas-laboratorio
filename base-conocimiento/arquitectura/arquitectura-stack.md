# Arquitectura y stack tecnológico

> Fuente académica pendiente. Contenido complementario general.

## Definición y propósito

La arquitectura organiza responsabilidades, componentes, interfaces y restricciones; el stack enumera tecnologías concretas que realizan esas responsabilidades.

## Elementos y reglas

Separar decisiones lógicas de productos, mostrar dependencias e interfaces y justificar cada tecnología por requisitos o restricciones.

## Ejemplo disponible

`plantillas/arquitectura/ejemplo-arquitectura.mmd`.

## Errores frecuentes

Presentar una lista de marcas como arquitectura o introducir tecnología sin relación con el problema.
