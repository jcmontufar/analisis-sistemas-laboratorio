# DFD de contexto

> Reglas académicas y alertas consolidadas: `reglas-integradas.md`.

## Definición y propósito

Vista de máximo nivel que representa el sistema como un solo proceso y muestra su intercambio de datos con entidades externas.

## Elementos y reglas

Proceso 0 cuando corresponda, límite implícito, entidades externas y flujos de datos nombrados y dirigidos. Debe balancear con el nivel cero.

## Ejemplo disponible

`plantillas/dfd/ejemplo-contexto.puml`.

## Errores frecuentes

Incluir almacenes internos, representar control en vez de datos o dejar flujos sin nombre.

## Fuente académica

Instrucciones DERCAS, “DFD Contexto”; PPTX, diap. 8; ejemplo PNG 14. Kendall y Kendall se prioriza solo si el ejercicio lo solicita.
