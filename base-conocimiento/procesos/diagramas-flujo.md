# Diagramas de flujo

> Fuente académica pendiente. Contenido complementario general.

## Definición y propósito

Representación gráfica del orden de actividades, decisiones y rutas alternativas de un procedimiento.

## Elementos y reglas

Inicio/fin, actividad, decisión, flujo y conectores; usar carriles para responsabilidades. Cada decisión debe rotular sus salidas.

## Ejemplo disponible

`plantillas/flujo/ejemplo-carriles.drawio`, generado por script.

## Errores frecuentes

Decisiones con una sola salida, flechas sin dirección, cruces excesivos y actividades sin responsable cuando este es relevante.
