# Descripción, pasos, flujo y cronograma

## Definiciones y objetivo

La descripción técnica expresa reglas en español estructurado; el listado descompone el proceso hasta acciones primitivas; el flujo muestra secuencia, decisiones y responsables; el cronograma ubica actividades verificables en el tiempo.

## Reglas académicas explícitas

- Usar estructuras como SI/ENTONCES y ciclos; descomponer sistema → subsistema → proceso → pasos atómicos. Fuente: `05-Requirements_Engineering.pdf`, págs. 12–13.
- En DERCAS, cada proceso incluye número, nombre, descripción y responsable; su diagrama de flujo contiene al menos una decisión. Fuente: instrucciones DERCAS, sección “Procesos a automatizar”; PPTX, diap. 7.
- El cronograma DERCAS tiene al menos 45 actividades no genéricas; debe identificar quién/departamento/instrumento. Fuente: instrucciones DERCAS, sección “Cronograma”; PPTX, diap. 10.

## Ejemplos y convenciones

`09-DescripcionDelProceso.png` ilustra narrativa; `10-DescripcionProceso.png` muestra numeración jerárquica y responsables; `16-DiagramaDeActividades.png` muestra carriles. Complemento: toda decisión debe tener guardas mutuamente comprensibles y cada actividad un resultado verificable.

## Vacíos

No se fija notación obligatoria para el diagrama de flujo ni unidad temporal del cronograma; deben tomarse del enunciado.
