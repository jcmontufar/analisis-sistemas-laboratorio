# Sistemas de información

> Base académica incorporada; véase también `ciclo-vida-y-metodos.md`.

## Definición y propósito

Conjunto coordinado de personas, procesos, datos y tecnología que captura, transforma, almacena y distribuye información para apoyar operaciones y decisiones.

## Elementos y reglas

- Entradas, procesos, salidas, almacenamiento y retroalimentación.
- Delimitar propósito, alcance, actores, interfaces y restricciones antes de modelar.

## Ejemplo disponible

La arquitectura mínima de `plantillas/arquitectura/ejemplo-arquitectura.mmd` ilustra interfaz, servicio y datos.

## Errores frecuentes

Confundir el sistema de información con el software solamente o modelar sin límite de alcance.
