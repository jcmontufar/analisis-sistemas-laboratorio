# Diagrama entidad-relación

> Fuente académica pendiente. Contenido complementario general.

## Definición y propósito

Modelo de entidades, atributos, identificadores y relaciones con cardinalidades para representar datos del dominio.

## Elementos y reglas

Entidades, atributos, claves, relaciones, obligatoriedad y cardinalidad. Resolver relaciones muchos-a-muchos al llevar el modelo a un esquema relacional.

## Ejemplo disponible

`plantillas/entidad-relacion/ejemplo-modelo.dbml`.

## Errores frecuentes

Confundir una clase de dominio con una tabla, omitir claves o introducir redundancia sin justificación.
