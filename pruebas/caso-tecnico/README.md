# CASO_TECNICO_DE_PRUEBA

Simulación metodológica aislada. No es un ejercicio académico real ni una solución reutilizable.

Caso mínimo: “Una biblioteca registra préstamos de libros.”

Objetivo: comprobar creación de carpeta, selección de fuentes, análisis mínimo, generación editable, render SVG/PNG y checklist.
